# Capability report: 2026-10-12, aarch64 sandbox, 2 vCPU, ~8 GB RAM, no GPU

| Tool | Verdict | Notes / exact error |
|---|---|---|
| **Browser rig renderer** (Canvas2D in headless Chromium via Playwright, ffmpeg mux) | **Working (winner)** | `renderer/stage.js` draws painted layers plus a procedural face (eyes, lids, brows, mouth/jaw). Each frame is rendered deterministically and piped as JPEG to x264. 2 workers give ~5–6 fps, so 100 s per 17 s clip. |
| Playwright-bundled Chromium | Blocked | `Error: Download failed: server returned code 403 … URL: https://cdn.playwright.dev/builds/cft/153.0.8010.12/linux-arm64/chrome-linux-arm64.zip`. Workaround: `apt-get install chromium` + `executable_path=/usr/bin/chromium`. |
| Rhubarb Lip Sync 1.14.0 | **Working** | No aarch64 release, so built from source. Full `cmake --build .` fails only in `extras/EsotericSoftwareSpine … rhubarbForSpine] Error 1` (Java extra). `--target rhubarb` builds fine. Takes ~3 s per 17 s clip with `-d` dialog text and `--extendedShapes GHX`. |
| Kokoro-82M (kokoro-onnx) | **Working (TTS used)** | Load 1.2 s, ~0.55× real-time on CPU. Voices are preset style vectors plus blends. **It is not a prompted voice design.** Gives no word timings, so caption timings are syllable-weighted per sentence (approximate). Lip sync comes from the real audio via Rhubarb. |
| VoxCPM2 (`pip install voxcpm`, voice design) | **Blocked (OOM)** | Installed in `.venv-vox` (torch CPU). Weights download OK (4.7 GB). Both runs were killed while loading the 2B model: `Running on device: cpu, dtype: bfloat16` → `Killed … exit=137`. The second run had nothing else running. Stopped after 2 failures, as the brief asks. `character.json` for Chris keeps `voice.provider=voxcpm` with the design prompt. `VOXCPM_OK=1 python3 run.py …` uses it on a box with ≥16 GB RAM. |
| edge-tts 7.2.8 (graph's declared voice for Ralph) | **Blocked** | 1) aiohttp rejects the sandbox proxy URL: `ValueError: A ":" is not allowed in login (RFC 1945#section-11.1)`. 2) Without the proxy: `WSServerHandshakeError: 403, message='Invalid response status', url='wss://speech.platform.bing.com/consumer/speech/synthesize/readaloud/edge/v1?…Sec-MS-GEC-Version=1-143.0.3650.75'`. Ralph uses the Kokoro stand-in from `rig.json.voice_fallback`, labelled `kokoro-82m:…` in every report. `EDGE_TTS_OK=1` re-enables edge-tts. |
| Rive CLI | **Blocked (platform)** | `install.sh`: `rive-cli is not shipped for Linux aarch64 yet (x86_64 only).` Docs: an account is only needed for `--publish`/`--rev`, so no login was attempted. |
| Agent Theater (MIT) | Not used | A browser paper-theatre app driven through WebMCP and an LLM agent. The useful idea, typed stage controls the agent drives, is already how `director.py` emits events. Nothing to run headless for video. |
| OpenMontage (AGPL) | Not used (eval by reading only) | Its HyperFrames HTML/GSAP rigged-SVG path is the same family as our renderer. Its headline animation relies on paid generators (Kling, Veo). No code taken because of AGPL. |
| Remotion | Not tested | Not needed: the Playwright frame-stepper is the same technique without the licence or bundle overhead. |
| PIL/skia compositing | Rejected (user requirement) | PIL is only used offline to cut layers (`prep_rig.py`). No frames come from PIL. |
| generate_image (layered art) | Partial | Gives a strong single-style character sheet and a reliable "blank-face" edit. It could not produce true separate layers, so `prep_rig.py` cuts head/jaw/body/collar and the face parts are drawn procedurally. Face anchors are hand-placed in `rig.json` (no landmark model). |
